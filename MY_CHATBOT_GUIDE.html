كود موزّع على أزرار مختلفة، وكل زرار بيبعت رسايل للتاني.

ليه؟ 3 أسباب

  • الليست لازم تكون في مكان واحد. في mBlock كل سبرايت ليه ذاكرته لوحده — لو الليست على زرار، الزرار التاني مش هيشوفها. ودي بالظبط الغلطة اللي في الملف الرسمي.
  • سبرايت واحد = مكان واحد تدوّر فيه لما حاجة تبوظ. مش هتلف على 12 سبرايت تدوّر على الغلط.
  • مفيش رسايل (broadcast) = مفهوم أقل يتشرح. المفاهيم الجديدة النهارده تبقى واحد: الليست.
🎁 والأزرار الخضرا والحمرا؟ سيبها لآخر الحصة كزيادة للي خلّص بدري (المرحلة 6). مش أساسية.

الأربعة دول سبب كل الأخطاء اللي هتقابلك. اكتبهم على السبورة وسيبهم طول الحصة.

أي سطر بيبدأ بـdef أو if أو elif أو else أو for — لازم ينتهي بـ:

2️⃣ الروبوت بيسأل ويرد

دلوقتي بقى محادثة. غيّر السطر الأخير وزوّد سطر:

✅ الشيك بوينت: دوس على الروبوت → هيطلع مربع تكتب فيه تحت الشاشة → اكتب أي حاجة → الروبوت يعيدها عليك.

اللي هتقوله

  • «input() بيقف ويستنّاك تكتب. اللي بتكتبه بيتحط في choice.»
  • «علامة + بين كلامين بتلزّقهم في بعض.»
🎭 لعبة سريعة (دقيقتين): خليهم يكتبوا أسماءهم ويشوفوا الروبوت بيرد. الفصل هيتبسط، وإنت كسبت انتباههم قبل الجزء الصعب.

حاول يجمع كلام مع رقم. 'You said: ' + choice شغّالة لأن الاتنين كلام. لكن لو جمع رقم لازم str(الرقم).

from mblock import event

tasks = []


@event.clicked
def on_clicked():
    choice = input('add / show / done')

    if choice == 'add':
        task = input('What do you need to do?')
        tasks.append(task)
        sprite.say('Added!', 2)
📌 السطر sprite.say('You said: ...') اتشال. ده السطر الوحيد اللي هيتشال في الحصة كلها.
⚠️ خد بالك من مكان tasks = []: لازم يكون برّه الدالة، مالزق على الشمال خالص. لو حطّه جوه، الليست هتترسم من أول وجديد كل مرة والمهام هتضيع. ده أشهر غلط.
✅ الشيك بوينت: دوس على الروبوت → اكتب add → اكتب «حل الرياضة» → لازم يقول Added!. كرّرها 3 مرات.
🤔 السؤال الذكي اللي تسأله هنا: «طيب فين المهام دلوقتي؟ إحنا مش شايفينها!» — سيبهم يفكروا شوية، وده بيوصّلك للمرحلة الجاية طبيعي.
🐛 IndentationError
أشهر خطأ في الحصة. اللي جوه if لازم يبقى 8 مسافات (Tab مرتين)، واللي جوه def بس 4 (Tab مرة). خليه يستخدم Tab مش المسطرة.
🐛 كتب Add بحرف كابيتال ومحصلش حاجة
ودي فرصة تعليمية ممتازة! 'Add' مش 'add' عند الكمبيوتر. قوله: «شوفت؟ الكمبيوتر بيفرّق بين الكبير والصغير.» الحل الأنضف: input(...).lower() — تقدر تزوّدها كزيادة.

from mblock import event

tasks = []


@event.clicked
def on_clicked():
    choice = input('add / show / done')

    if choice == 'add':
        task = input('What do you need to do?')
        tasks.append(task)
        sprite.say('Added!', 2)

    elif choice == 'show':
        for i in range(len(tasks)):
            sprite.say(str(i + 1) + '. ' + tasks[i], 2)

    elif choice == 'done':
        number = int(input('Which number is done?'))
        tasks.pop(number - 1)
        sprite.say('Well done!', 2)
