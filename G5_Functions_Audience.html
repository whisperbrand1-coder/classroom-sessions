PART 1 · THE TIDY-UP TRICK ⚙️

What is a Function?

A named piece of code that does one specific job — and you can use it again and again.

THE IDEA

Give your code a name 🏷️

Imagine you write the same 4 blocks ten times. Instead — wrap them once, give them a name, and just call the name.

🧹

Clearer

The code reads like a sentence.

🔧

Easier to fix

Change it in one place, not ten.

♻️

Reusable

Use it any time you need it.

🍰 Real life: “make a sandwich” is one name — but inside it there are many steps (bread, butter, cheese, close). You don't list the steps every time; you just say “make a sandwich”. That's a function!

TEAM ACTIVITY · 30 MIN 🎁

Guess The Event

4 TEAMS

Design a card — can they guess it?

Split into 4 teams: A, B, C, D. Teams work in pairs (A+B, C+D).
Team A designs a logo for an event (Mother's Day, Egypt's National Day…) — but don't write the name!
Pass it to Team B. They guess the event and write a greeting sentence.
Swap! Now Team B designs a new event's logo and Team A guesses.
Both teams present their cards. The pair with the best cards wins! 🏆
🎨 Why this matters: a good logo communicates without words — exactly like a good function name tells you what it does without reading inside it.

SECRET AGENT TIME 🔐

Decode a Cipher

A cipher is a secret code. Ours shifts every letter one step down the alphabet.

THE RULE

Shift by one ➡️

To encode: move each letter forward one place. To decode: move each letter back one place.

LetterIts numberShift +1Becomes
A12B
G78H
E56F
🔤 So the word AGE becomes BHF. And to read a secret word, you do the opposite — go back one letter.
