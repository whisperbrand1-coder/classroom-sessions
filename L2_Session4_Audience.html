CHAPTER 1 · THINK LIKE AN ATTACKER ⚔️

Offensive Security

Attacking systems — legally — to find weaknesses before the bad actors do.

PROACTIVE

What is offensive security? ⚔️

Instead of waiting for an attack, professionals simulate attacks — like real hackers would — to find and fix weaknesses first. This is ethical hacking (or red teaming).

✅

Legal & authorized

Attack simulations with permission.

🔎

Find vulnerabilities

Before real hackers do.

📝

Report to improve

Findings + how to fix them.

🏪 ANALOGY You open a new shop. Instead of waiting for a thief, you hire a security expert: “Try to get in — legally — and tell me which doors and locks are weak.” That's ethical hacking.
🏢 Real example: companies hire ethical hackers to test their websites — looking for open ports, outdated software or login weaknesses — then get a full report.
THE TOOLKIT 🧰

Offensive security tools

Know what each tool is for — not how to run it.

🚪

Nmap

Scans for open ports & running services — the doors of a computer.

💥

Metasploit

Tests whether known exploits actually work on a system.

🕸️

Burp Suite

Tests web app flaws (e.g. broken authentication).

🔬

Wireshark

A microscope for network traffic — spots unencrypted or odd data.

CONNECT Job ↔ tool

Three types of offensive security 🎯

🎯

Penetration Testing

Focused & time-limited on one system, with a defined scope & a report.

🥷

Red Teaming

Full simulation: tech + social engineering + physical entry — the whole org.

🏆

Bug Bounty

Independent researchers report bugs responsibly & earn rewards (Google, Meta).

SORT Scenario → type

THE GOLDEN RULE ⚖️

No Permission = Illegal

✅ RULES

Always

  • Get written permission first
  • Respect the scope — only test what's allowed
  • Document everything
  • Never cause harm
  • Report findings responsibly
⚠️ WARNING

Never

Unauthorized testing — even with good intentions — is still illegal. Accessing a system without permission, even to “help”, can bring serious legal consequences.

The only difference between an ethical hacker and a criminal is permission and staying in scope.

CHAPTER 2 · PROTECT & DEFEND 🛡️

Defensive Security

Three goals: Prevent the attack, Detect it, and Respond when it happens.

Prevent · Detect · Respond 🏠

Think of protecting your home.

🚪

Prevent

A strong door & a lock — stop it happening.

📹

Detect

A camera or alarm — notice it fast.

🚓

Respond

Call security & isolate — limit the damage.

SORT There is no 100% — you need all three

THE DEFENDER'S KIT 🧰

Common defensive tools

🦠

Antivirus

A doctor that scans files for known threats.

🧱

Firewall

A gate guard: who may enter & leave the network.

🔒

Encryption

Scrambles data — useless to a thief without the key.

📜

Log Analysis

The record: who, when, from where, and how many failed logins.

CONNECT Job ↔ tool

🧅 LAYERS

Defense in Depth

Never rely on one defense. Stack layers like an onion — if an attacker gets past one, another is waiting.

🏢 Physical — the office door is locked.
🌐 Network — a firewall filters traffic.
💻 Endpoint — the device needs a password.
📱 Application — the account uses MFA.
🗄️ Data — the files are encrypted & activity is logged.
🎣 Phishing in action: ① a filter blocks most emails (Prevent) → ② one slips through & a trained employee reports it (Detect) → ③ the security team investigates → ④ they block the sender & update systems (Respond). Notice the employee is part of the security system — not just the computer.
CHAPTER 3 · THE 3 A's 🔑

AAA Security

Not battery sizes 😄 — Authentication, Authorization, Accounting.

🪪

Who are you?

Authentication

🎫

What can you do?

Authorization

📝

What did you do?

Accounting

🪪 AUTHENTICATION

Who are you?

Proving your identity uses three kinds of factors.

🧠

Something you know

Password, PIN, security question.

📱

Something you have

Phone, authenticator app, token.

🫆

Something you are

Fingerprint, face, iris.

SORT Know · Have · Are

📲 MFA = two different factors. Password + PIN is weak (both “know”). Password + phone code, or password + fingerprint, is strong. If a thief steals your password but the code is on your phone — they’re stuck.
🎫 AUTHZ

What can you do?

After we know who you are, we set your permissions.

  • 🎓 Student → view own grades
  • 👩‍🏫 Teacher → edit grades
  • 🏫 Admin → add teachers
🚪 Authentication got you in the building; authorization decides which rooms you may enter.
📝 ACCT

What did you do?

The system records activity: who logged in, when, which file they opened, what changed, failed logins.

Used for troubleshooting, spotting suspicious behavior, digital forensics & legal compliance.

🕵️ “The grades file changed at 3 AM.” The logs tell us who and from which device.
MATCH THE A 🔤

Why AAA matters

No Authentication → anyone claims to be anyone. No Authorization → anyone opens any data. No Accounting → we never learn who did it.

CHAPTER 4 · WHEN THINGS GO WRONG 🚨

Signs, Response & Careers

Most attacks don't announce themselves with “You are hacked”. Learn the warning signs — and the plan.

5 signs of a cyber attack 🕵️

🐌

Unusual device behavior

Sudden slowness, strange apps, crashes, overheating, programs opening themselves.

👤

Suspicious account activity

Password changed, messages you didn't send, login from another country.

🪟

Pop-ups & redirects

Lots of ads, fake virus warnings, browser opening odd sites.

🚫

Disabled security tools

Antivirus turned itself off and won't restart — a strong sign.

📡

Unknown network activity

High data use, big uploads for no reason.

SPOT IT Warning sign or normal?

FIRST RESPONSE

If you suspect a problem 🧯

Report it — tell IT / the security team.
Disconnect / isolate the device if needed.
Scan the system.
Update software.
Change passwords — from a safe device.
Preserve evidence — don't wipe everything randomly.
🏢 At work, don't act alone and format the machine — report to IT / Security first. Random wiping destroys evidence.

PART 2 · SWITCHING HATS 🎨

Digital Art & Design

Now we think like creators. Same skill of “how things are built & how they read” — pointed at beauty & meaning.

DIGITAL ART

What is digital art? 🖌️

Any artwork made or edited with technology — computer, tablet, phone, drawing or animation software.

🎮 Game characters🖼️ Posters🎬 Movie effects🏷️ Logos📱 Social designs

Why artists love it

↩️ Undo🗂️ Layers📋 Copy & transform🎨 Try many colors⚡ Share fast
🧠 “Digital” does not mean the computer draws for you. You still need the idea, composition, color & skill.

Art vs Design 🎭

ART

Express

Goal: expression, emotion, story, personal interpretation. Everyone may read it differently.

Asks: “What do I want to express?”

DESIGN

Solve

Goal: solve a problem, communicate clearly, help an audience achieve a purpose. Balances creativity & function.

Asks: “What does the user need to understand or do?”

SORT Art or Design?

Design speaks without words 🗣️

🎨

Color

Red = urgency/energy, Blue = trust/calm, Green = nature/success. Meaning shifts with culture.

🔤

Typography

Bold = power, Script = elegant, Rounded = friendly, Monospace = technical.

📐

Layout

Tells the eye where to look first, next, and what matters most.

🔁 Design is iterative. Process: Understand → Brainstorm → Prototype → Feedback → Refine. Design Thinking: Empathize → Ideate → Prototype → Test. A good designer never treats the first idea as final.

🧊

HOW TO COOK THE INGREDIENTS 👨‍🍳

Principles & Composition

If Elements are the ingredients, Principles are the recipe — how you arrange everything.

Principles of Design 📐

⚖️

Balance

Distribute visual weight (symmetrical or asymmetrical).

📏

Proportion

Sizes relative to each other.

➰

Movement

How the eye flows through the design.

🌗

Contrast

Light/dark, big/small, warm/cool.

⭐

Emphasis

The one most important element.

📎

Alignment

Elements on a clear system.

🔁

Repetition

Repeat colors/shapes/fonts → consistency.

🍳

The recipe

Same ingredients, different arrangement = different feeling.

HOW THE BRAIN GROUPS 🧠

Gestalt principles

Your brain organizes shapes into groups automatically.

CONNECT Principle ↔ effect

👀 Examples: blue buttons that share a job (Similarity) · a circle with a gap we still read as a circle (Closure) · a logo where a shape hides in the background (Figure-Ground).

ARRANGE THE STAGE 🎬

Composition

It's not enough for each part to be nice — they must work together.

  • Focal Point — the first place the eye lands (size, color, contrast, position).
  • Visual Hierarchy — title → image → details → notes.
  • Rule of Thirds — place key elements near the intersections, not dead center.
  • Leading Lines — roads, rivers, a character's gaze pull the eye.
  • Negative Space — empty space isn't wasted; it makes the main thing clearer.
  • Depth — foreground/midground/background & overlap.
🎯 In the picture: the focal point (orange dot) sits on a rule-of-thirds intersection, and the green leading line guides your eye toward it.
MAKING IT LOOK REAL 🌈

Sketching, Light, Perspective & Color

The tools that turn flat shapes into a believable world.

✏️ SKETCH

Sketching — big shapes first

A sketch doesn't need to be perfect. It trains your eye & hand and fixes proportions early.

From lines to forms

Head → SphereBody → Cylinder/BoxCup → CylinderCar → Boxes & circles
Block In — the big shapes.
Add details — once the big shapes are right.
Refine — clean it up.
🧠 Start big, then small. Don't draw eyelashes before you're sure the head is in the right place. Most things = cubes, spheres, cylinders & cones.
FIND THE LIGHT 💡

Light & shadow

  • ☀️ Highlight — brightest spot facing the light.
  • 🌑 Core Shadow — the dark band on the object itself.
  • ⬛ Cast Shadow — the shadow it throws on the ground.
  • ↩️ Reflected Light — faint light bouncing back into the shadow.
💡 Before shading, ask: “Where is the light?” Light from the left → highlight left, shadows right. Sphere = smooth transition; cube = sharp transition.
DEPTH ON A FLAT PAGE 🛣️

Perspective

  • Horizon Line — the viewer's eye level.
  • Vanishing Point — where parallel lines seem to meet.
  • One-Point Perspective — lines to a single point (a hallway, a road).
  • Scale — far things look smaller.
  • Overlap — the object in front covers the one behind.
COLOR THEORY 🎨

Color theory

🔴

Primary → Secondary

Red/Yellow/Blue mix into Orange/Green/Purple; mix again for Tertiary.

🎚️

Hue · Saturation · Value

The color's name · how vivid · how light/dark.

🌡️

Warm vs Cool

Warm = energy/heat; Cool = calm/distance.

SORT Warm or Cool?

🎨 Harmony: Complementary (opposite = high contrast) · Analogous (neighbors = calm) · Monochromatic (one color, many values). Don't use every color — pick a Dominant + Supporting + Accent.
DIGITAL IMAGING 🖥️

Raster vs Vector

Zoom in and watch the difference 👇

ZOOM TEST Pixels vs math

🖼️ Raster = pixels (JPG, PNG). Great for photos & painting; blurs when over-zoomed.
⭐ Vector = math paths (SVG). Great for logos & icons; scales to any size, always sharp.
📁 Formats: JPG (photos, small, no transparency) · PNG (transparent background) · SVG (vector) · PSD (layered working file) · MP4 (video).   Aspect ratio: 1:1 square · 16:9 video · 9:16 story.   Workflow: Create → Edit → Save (editable) → Export (final) → Share.
PART 3 · FROM IDEA TO ARTWORK 🖼️

Visual Storytelling Workflow

References → Mood Boards → Ideas → Thumbnails → Critique → Final Artwork.

Reference vs Mood board 📌

Artists don't draw everything from memory.

📎 REFERENCE

“What does it look like?”

Objects, clothes, buildings, poses, materials — helps with proportion, lighting & texture.

🎭 MOOD

“What should it feel like?”

Colors, lighting, atmosphere, emotional images — sets the feeling.

SORT Reference or Mood?

⚖️ Ethics: Using a reference = study the pose/light/color, then make something new. Copying = tracing someone's art and calling it yours. Respect copyright & give attribution — never claim others' work.
GENERATE IDEAS 💡

Inspiration & ideation

🌱

Subject vs Theme

Subject = what you see (a tree in a ruin). Theme = the meaning (hope, nature returning).

🎭

Mood

Built from color, light, shape & composition.

🔀

Combine opposites

Fire + Ice · Robot + Flower · Train + Sea creature.

IDEA MACHINE Word lists & “what if?”

🎯 Pick the strongest concept: score each idea 1–5 on Originality, Visual Interest, Time & Tools, Skill, and Motivation. The strongest isn't the hardest — it's beautiful AND doable.
TINY TESTS 🖼️

Thumbnails & iteration

A thumbnail is a tiny, fast sketch that tests placement, balance, light/dark, depth & camera angle — not details.

Iteration = make a version, review, change one clear thing, repeat. Don't change ten things at once or you won't know what helped.

KIND & USEFUL 💬

Critique

Critique the work, not the person.

❌ “You can't draw.” (attacks the person, not useful)
✅ “The main character is hard to see because it's the same color as the background.” (a fixable element)
