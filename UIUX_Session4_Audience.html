UI/UX Design Fundamentals

How good apps look, work, and guide users.

UI vs UX 🎨🧠

Great apps need both a beautiful surface and a smooth experience.

UI

Focuses on look

  • Colors, typography, buttons, visual style
  • Makes the app attractive & clear
  • Supports the brand feeling
🎨 Example: the exact shade of blue, the font, and the rounded button corners.
UX

Focuses on use

  • How the app works & feels
  • Smooth, intuitive user journey
  • Helps users complete tasks easily
🧠 Example: checkout takes 2 taps instead of 6 — that's UX.

The rules that make an interface feel trustworthy.

👁️

Clear hierarchy

Guides the user's eye to what matters first.

🔁

Consistency

Helps users learn the app quickly.

⬜

Whitespace

Makes screens cleaner & easier to read.

📱

Responsive behavior

Keeps the experience smooth across devices.

💡 Example: a big bold title + smaller subtitle = hierarchy. The same button style on every screen = consistency.

APP IDEA

Planning an app concept 💡

Before designing, define the story of the app.

Define the purpose and target audience.
Outline 3–5 essential features only.
Sketch a user flow from opening the app to one key action.
List the screens needed for that flow.
💡 Example: A water-reminder app → purpose: drink more water; audience: busy students; flow: open → log a glass → see progress. Screens: Home, Log, Progress.

CLEAN DESIGN

Alignment & layout 📏

Clean structure makes designs feel professional.

  • Grids, columns & rows create order.
  • Alignment tools position elements precisely.
  • Smart guides help center & space objects quickly.
  • Auto Layout adjusts spacing & padding automatically.
💡 Auto Layout example: add a new button to a menu and everything re-spaces itself — no manual nudging. Great for responsive designs.
DESIGN SYSTEM

Styles & components ♻️

Consistency saves time and reduces mistakes.

🎨

Styles

Color & text styles keep the design on-brand. Update one style → it updates everywhere it's used.

🧩

Components

Reusable design elements. Instances can be overridden without changing the main component.

🧩 Example: make one “Primary Button” component → reuse it on 20 screens. Change its color once → all 20 update.
CHAPTER 3 · THE BLUEPRINT 📐

Wireframing Essentials

From rough sketches to testable app flows.

What is a wireframe? 📐

A blueprint for the app before visual polish.

  • Shows where everything goes.
  • Focuses on function, not fashion.
  • Helps identify usability issues early.
  • Low-fidelity sketches are quick & flexible.
🏷️ Session 15
💡 A wireframe is grey boxes on purpose — it keeps the team focused on layout & flow, not colors yet.
LOW-FI

Sketch first, then build ✏️

Paper or FigJam helps you explore ideas quickly.

Map the user journey with boxes and arrows.
Sketch only the key screens.
Use simple shapes for images, buttons and text.
Review and redraw before investing in detail.
✏️ Why paper first? It's fast and cheap to change. You'll throw away 5 sketches before you love one — that's the point.

USER FLOW

Navigation & testing 🧭

A flow is only good if users can follow it.

  • Use buttons, back navigation, tab bars or menus.
  • Connect screens to simulate the user journey.
  • Test with a simple task script.
  • Observe confusion and iterate.
🧪 Test script example: “Book a ride from home to school.” Watch where the user hesitates — that spot needs a redesign.

GROUP ACTIVITY 1 · 25 MIN 📐

Concept → Wireframe

GOAL

Turn an app idea into a clear low-fidelity flow

  • Use UI/UX principles to define a simple app concept.
  • Map one core user journey with screens and arrows.
  • Create 3 low-fidelity screens in Figma using frames, shapes and text.
📄 Open the activity worksheet
STEP BY STEP 🪜

Activity 1 — how to

Work in groups and keep the design low-fidelity.

Choose an app idea — pick a simple concept, or improve an idea from Session 13.
Define purpose — state the problem, target users, and one main goal.
Map the flow — draw the path from opening the app to completing one key action.
Create screens — build 3 wireframe screens in Figma using frames, shapes and text.
Add navigation — add buttons, back arrows, or a tab bar to guide users.
Quick share — explain one UX choice that makes your flow easy to use.

GROUP ACTIVITY 2 · 20 MIN 🎛️

Prototype & Polish

GOAL

Convert one wireframe flow into a simple interactive hi-fi prototype

  • Apply a small brand style: colors, typography & spacing.
  • Create an interactive button state or navigation click in Figma.
  • Preview, peer-test and fix one issue before sharing.
📄 Open the activity worksheet
STEP BY STEP 🪜

Activity 2 — how to

Use the wireframe from Activity 1 as your starting point.

Select one flow — choose the 3-screen flow you built in Activity 1.
Apply brand style — a limited color palette, clear typography, consistent spacing.
Build a component — turn the main button into a component with Default and Pressed states.
Add interaction — use Prototype mode to connect screens and add a While pressing trigger.
Preview and test — click Play, complete the task, and let another group try it.
Polish one issue — fix clutter, contrast, an unclear button, or missing navigation.
