🎨 ترسم صفحات التطبيق إزاي

ده الجزء اللي العيال هتقضي فيه معظم الوقت. الفكرة: تسحب عنصر من الصندوق وترميه على شاشة الموبايل.

اضغط Design عشان تدخل وضع التصميم.
هتلاقي قايمة عناصر. أهمهم اللي هنستخدمهم:
• Button = زرار.
• Label = كلام/عنوان ثابت.
• Text Input = خانة المستخدم يكتب فيها.
• Image = صورة.
اسحب العنصر واحطّه على شاشة الموبايل. سيبه في مكانه.
لما تدوس على العنصر، بتظهر خصائصه. غيّر منها:
• id = اسم العنصر (مهم جدًا للبرمجة — سمّيه باسم واضح زي loginBtn).
• text = الكلام المكتوب عليه.
• الألوان والحجم.
تعمل صفحة جديدة: فوق شاشة الموبايل في وضع Design هتلاقي اسم الشاشة الحالية (screen1) وجنبه خيار إضافة شاشة — اضغطه واختار New screen. سمّي الشاشات: signup / login / home.
⚠️ أهم نصيحة: خلّي العيال يسمّوا كل عنصر باسم مفهوم من الأول. لو سابوا الأسماء الافتراضية (button1, button2, button3) هيتوهوا لما ييجوا يبرمجوا.

🔗 تربط الأزرار بالصفحات (أهم خطوة)

التصميم لوحده مش تطبيق. لازم لما ندوس على زرار، ينقلنا لصفحة تانية. ده بيتعمل في وضع Code.

اضغط Code.
من صندوق البلوكات دوّر على قسم UI controls وهتلاقي بلوك onEvent — اسحبه لمساحة الشغل.
في البلوك ده حدّد: اسم الزرار (id) ونوع الحدث "click".
جوّه البلوك ده حط بلوك setScreen واختار اسم الشاشة اللي عايز تروحلها.
اضغط ▶ Run فوق شاشة الموبايل وجرّب تدوس على الزرار.

لو حبيت تشوف الكود كنص (أو تشرحه للعيال المتقدمين)، شكله كده بالظبط:

// لما المستخدم يدوس على زرار الدخول → روح لصفحة الهوم
onEvent("loginBtn", "click", function() {
  setScreen("home");
});

// ولو دوس على "معنديش حساب" → روح لصفحة التسجيل
onEvent("signupLink", "click", function() {
  setScreen("signup");
});
✅ ده كل السر. تطبيق كامل من 3 أو 4 صفحات = مجموعة بلوكات onEvent → setScreen، واحد لكل زرار. مفيش حاجة أصعب من كده في الدرسين.

تحفظ وتشارك

  • الحفظ أوتوماتيك طول ما إنت مسجّل دخول.
  • عشان تشارك: زرار Share فوق → بيديك لينك تبعته أو تحطه على البروجيكتور.
  • ترجع لمشاريعك من studio.code.org/projects.

🤖 تدريب الـAI على الوشوش (أهم جزء)

ده قلب مشروع Class Monitor. الفكرة إنك بتعلّم الكمبيوتر شكل كل طالب، وبعدين هو يعرف يميّزه.

اتأكد إنك في وضع Sprites (مش Devices) من التبويبات تحت المسرح.
تحت صندوق البلوكات خالص اضغط + Extension (أو Add Extension).
دوّر على Teachable Machine واضغط + Add. هتلاقي قسم بلوكات جديد ظهر عندك.
اضغط على بلوك فتح نافذة التدريب (Training Model / TM). هتفتح نافذة فيها الكاميرا.
هتلاقي Class 1 — اضغط على اسمها وغيّره لاسم الطالب (مثلًا mostafa).
خلّي الطالب يقف قدام الكاميرا، واضغط مستمر على زرار Learn لمدة ٣-٥ ثواني — البرنامج بياخد صور كتير. خلّيه يلف وشه شمال ويمين شوية عشان يتعلم أحسن.
اضغط New Class وكرّر لكل طالب (ahmed… إلخ). محتاج على الأقل ٢-٣ كلاسات.
اضغط Train Model واستنى لحد ما يخلص، وبعدين اقفل النافذة.
✅ اختبار سريع: بعد التدريب، النافذة بتوريك اسم الكلاس اللي شايفه دلوقتي. قف قدام الكاميرا وشوف بيقول اسمك ولا لأ. لو صح — الموديل جاهز.
💡 نصايح تخلي الدقة عالية:
• إضاءة كويسة على الوش (متقفش وضهرك للشباك).
• خلفية ثابتة قدر الإمكان.
• صور كتير لكل طالب (اضغط Learn شوية ثواني مش ضغطة سريعة).
• لو ضفت طالب جديد بعدين، لازم تعمل Train Model تاني.

🏫 مشروع Class Monitor — بالبلوك بالظبط

أنا فتحت الملفين اللي بعتهملي وقريت اللي جواهم فعلًا. دي التفاصيل الحقيقية مش تخمين:

اللي جوه الملفين

الحاجةالتفاصيل

🔴 ركّز: الكود مش على المسرح ولا على الروبوت — هو على السبرايت اسمه Start button1. لو فتحت الملف ومشوفتش بلوكات، إنت غالبًا واقف على سبرايت تاني. دوس على Start button1 الأول.

الكود بالظبط (نسخة المدرّس)

// على سبرايت: Start button1
when this sprite clicked
repeat 3
    set [first student]  to (recognition result)
    wait 5 seconds
    set [second student] to (recognition result)
    wait 5 seconds
    set [third student]  to (recognition result)
    wait 5 seconds
    stop this script

الكود ده بيعمل إيه بالبلدي؟

  • when this sprite clicked — البرنامج مش بيبدأ بالعلم الأخضر! بيبدأ لما تدوس على زرار Start اللي على المسرح.
  • set [first student] to (recognition result) — بلوك الـAI بيبصّ للكاميرا ويرجّع اسم الكلاس اللي عرفه، والبرنامج بيحفظه في المتغير.
  • wait 5 seconds — بيدي فرصة إن الطالب اللي بعده يقف قدام الكاميرا.
  • يكرّر ده ٣ مرات (٣ طلبة) وبعدين stop this script.
👀 عشان الحضور يبان قدام العيال: روح لقسم Variables وحط علامة ✔️ جنب المتغيرات التلاتة — هيظهروا على المسرح، وهتشوف الأسامي بتتكتب لحظة بلحظة. ده اللي بيخلي العيال تنبهر.

تشغّله إزاي في الحصة (الترتيب الصح)

File → Open واختار ملف Class monitor.mblock.
درّب الموديل الأول (القسم اللي فات) — سمّي الكلاسات بأسامي الطلبة الحقيقيين اللي هيقفوا.
دوس ✔️ على المتغيرات التلاتة عشان تظهر على المسرح.
دوس على زرار Start على المسرح (مش العلم الأخضر).
أول طالب يقف قدام الكاميرا → استنى → التاني → التالت. الأسامي بتتسجل.

نسخة الطالب — هما هيعملوا إيه

ملف Class monitor Student Version.mblock فيه كل حاجة جاهزة (السبرايتات والخلفية والمتغيرات) بس الكود فاضي. مهمة الطالب إنه يركّب البلوكات دي بنفسه:

يدوس على سبرايت Start button1.
من Events يسحب when this sprite clicked.
من Control يسحب repeat ويكتب فيه 3.
من Variables يسحب set [ ] to [ ] ويختار first student.
من قسم الـAI يسحب بلوك recognition result ويحطه جوه خانة القيمة.
من Control يسحب wait 5 seconds.
يكرّر للطالب التاني والتالت، وفي الآخر stop this script.
🎯 ده هدف الحصة بالظبط: إنهم يوصلوا بنفسهم إن «الحضور» = متغير + بلوك ذكاء اصطناعي + انتظار. بسيطة، بس فكرتها قوية جدًا.

من Events اسحب when started وحطه في مساحة الشغل.
من Drivetrain اسحب drive forward ولزّقه تحته.
من Control اسحب wait until.
من Operators اسحب بلوك المقارنة ( ) < ( ) وحطه جوّه خانة الشرط في wait until.
من Sensing اسحب FrontDistance in mm وحطه في الخانة الشمال من المقارنة، واكتب 50 في اليمين.
من Drivetrain اسحب turn left for 90 degrees ثم drive forward.
كرّر (wait until → turn → drive forward) على حسب شكل المتاهة، وفي الآخر stop driving.

🧩 تعمل Function (أهم فكرة في درس 2)

بعد ما الكود يطوّل جدًا، الدرس بيعلّمهم يقصّروه بـدالة (بلوك من صنعك). ده اللي هيفرق معاهم كبرمجيين.

من الـToolbox انزل تحت خالص لقسم My Blocks.
اضغط Make a Block.
اكتب اسم البلوك: Left
عايزه ياخد رقم (المسافة)؟ اضغط Add an input → اختار number → سمّيه distance.
اضغط OK — هيظهرلك في المساحة بلوك define Left (distance).
تحت الـdefine حط البلوكات المتكررة:
wait until ⟨(FrontDistance in mm) < (distance)⟩ ← اسحب كلمة distance من رأس الـdefine نفسها.
turn left for 90 degrees
drive forward
اعمل نفس الحاجة لبلوك اسمه Right بس باللف يمين.
دلوقتي في البرنامج الرئيسي استخدم Left 50 و Right 50 بدل ما تكرر ٣ بلوكات كل مرة.
// بدل ٣٠+ بلوك مكررة… بقى كده:
define Left (distance)
   wait until ⟨(FrontDistance in mm) < (distance)⟩
   turn left for 90 degrees
   drive forward

🎙️ إزاي تشرح وإنت مش خبير في الأداة

🧠 السر: إنت مش محتاج تعرف كل حاجة في الأداة — إنت محتاج تعرف المسار الواحد بتاع الحصة، وتعرفه كويس جدًا. أي حاجة برّه المسار ده، قول «سؤال حلو، تعالوا نجرّبه مع بعض».
اعرض الناتج الأول. ورّيهم المشروع شغّال (التطبيق/الروبوت/الحضور) قبل ما تبدأ تشرح. لما يشوفوا الهدف بيركّزوا.
ابنِ قدامهم على البروجيكتور بلوك بلوك، وقول بصوت عالي إنت بتعمل إيه وليه.
اغلط عمد مرة. حط بلوك في مكان غلط وورّيهم الروبوت بيتلخبط، وبعدين صلّحه. ده بيعلّمهم الـDebugging أكتر من أي كلام.
سيبهم يجرّبوا وإنت بتلف عليهم. متمسكش الماوس من إيد الطالب — قوله «اضغط إنت».
اقفل بسؤال: «مين يقدر يقولي بجملة واحدة الكود ده بيعمل إيه؟»

جمل جاهزة تستخدمها

  • «البرنامج مبيفكرش — هو بس بينفّذ اللي إحنا كاتبينه بالترتيب.»
  • «الحساس زي حاسة عندنا: العين والإيد. من غيره الروبوت أعمى.»
  • «TRUE يعني أيوه، FALSE يعني لأ. الكمبيوتر بيشتغل بالاتنين دول بس.»
  • «الفلوتشارت زي ما ترسم الطريق قبل ما تمشي فيه.»
